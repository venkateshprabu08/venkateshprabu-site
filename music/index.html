Music streaming demo

A self-hosted music server I run at home, built with Navidrome. This demo is separate from my own library and uses only licence-free and public-domain tracks.

  • Runs in Docker on a small Ubuntu home server
  • Shared publicly through Tailscale Funnel, with no ports opened on my router
  • Works in the browser and in Subsonic apps such as Tempo
  • Music: Jamendo (Creative Commons) and Open Lo-Fi (CC0)
