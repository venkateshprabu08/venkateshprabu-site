README

music-streaming: a self-hosted Spotify-style server

My own music streaming service, running on a small Linux server at home. It plays in the browser and in phone and desktop apps like a streaming service, but the server, the library and the data are all mine. This public demo is a separate copy with its own licence-free library, so anyone can try it without touching my private music. > open music demo cd .. https://linus.tail16ef75.ts.net

visitor@venkateshprabu:~/music-streaming$ cat how-it-works.txt

how it works

your browser or app | HTTPS request to linus.tail16ef75.ts.net v Tailscale Funnel | encrypted tunnel to my home server v home server "linus" | only the demo port is shared v navidrome-demo container | reads files, never writes v /srv/demo-music (mounted read-only) # no port forwarding on the router; the server makes the # outgoing connection, so it is not directly reachable.

visitor@venkateshprabu:~/music-streaming$ cat security.txt

security

- the demo is separate from my private library, which is not public - only the demo is exposed; every other service stays on the private VPN - the container runs as non-root, with read-only music and a memory cap - server firewall denies incoming traffic by default; SSH by key only - only licence-free music, so the demo can be shared openly
